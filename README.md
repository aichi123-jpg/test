# Beispielprojekt

Dieses kleine Beispiel zeigt die Codex-Funktion mit einem einfachen **"Hallo Welt!"**-Programm in einem Fenster.
Anschließend wird das **kleine Einmaleins (1 bis 10)** berechnet und im Fenster ausgegeben.

## Verhalten

- Das Programm öffnet ein Fenster.
- Oben im Fenster befindet sich ein **OK**-Button.
- Nach dem Schreiben der Ausgabe wird der Button aktiv.
- Mit **OK** kann das Fenster geschlossen werden.

## Ausführen

```bash
python3 hello.py
```
